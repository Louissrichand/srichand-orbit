# Orbit

ระบบจัดการงานแบบ Asana สำหรับใช้เองในทีม — HTML/CSS/JavaScript ล้วน ไม่มี build step ไม่มี dependency

## ลองใช้

**เปิดผ่านเว็บ:** https://Louissrichand.github.io/srichand-orbit/

**หรือเปิดในเครื่อง:** โคลน repo แล้วดับเบิลคลิก `index.html` ได้เลย

ไม่ต้องมี Node.js, ไม่ต้องมี Docker

## สิ่งที่ทำได้

### หน้าแรก
หน้าที่เปิดขึ้นมาเจอเป็นอย่างแรก สรุปว่าวันนี้ต้องดูอะไร — งานของฉัน โปรเจกต์ที่เข้าถึงได้
งานที่เรามอบหมายให้คนอื่น และกิจกรรมล่าสุด ทุกอย่างบนหน้านี้กรองตามสิทธิ์แล้ว
**ปรับแต่งหน้าแรก**ได้เอง — เพิ่ม ลบ ลากสลับ และย่อขยายครึ่ง/เต็มแถว จากวิดเจ็ต งานของฉัน งานที่ฉันมอบหมาย
โปรเจกต์ล่าสุด คนที่ทำงานด้วย อัปเดตสถานะ สมุดโน้ตส่วนตัว ร่างความเห็น สถิติงานเสร็จ และกิจกรรมล่าสุด
จำไว้ต่อคนในข้อมูลกลาง เปิดจากเครื่องไหนก็หน้าตาเดิม

### งานของฉัน
- **เซกชันของตัวเอง** สร้าง เปลี่ยนชื่อ เรียง ลบได้ งานที่มีคนมอบหมายมาลง "เพิ่งได้รับมอบหมาย" เสมอ ไม่ว่าจะมอบผ่านทางไหน
  ลากงานข้ามเซกชันได้ งานใหม่ที่ยังไม่ได้เปิดดูมี**จุดสีฟ้า** และยังจัดกลุ่มตามวันครบกำหนดแบบเดิมหรือตามโปรเจกต์ได้
- มุมมอง **รายการ บอร์ด ปฏิทิน (สัปดาห์/เดือน พร้อมแถบงานที่ยังไม่มีวันให้ลากลง) ไฟล์** ตัวกรอง เรียง จัดกลุ่ม จำไว้ต่อคนเอง
- **งานส่วนตัว** — งานที่สร้างจากงานของฉันโดยไม่ใส่โปรเจกต์ เห็นเฉพาะคนสร้าง ผู้รับผิดชอบ และผู้ติดตาม
  (ไม่โผล่ในค้นหา ปฏิทินรวม หน้าแรก โปรไฟล์ หรือกล่องข้อความของคนอื่น) กด "ทำให้เป็นสาธารณะ" เพื่อเลือกโปรเจกต์และคอลัมน์ที่จะวาง

### พอร์ตโฟลิโอ
กล่องรวมโปรเจกต์ไว้ดูภาพรวมทีเดียว เช่น สินค้าใหม่ปี 2027 หรือ งานฝ่ายการตลาด

- **รายการ** ตารางระดับโปรเจกต์ สถานะ ความคืบหน้า เจ้าของ กำหนดส่ง งานเลยกำหนด
- **ไทม์ไลน์** หนึ่งแท่งคือหนึ่งโปรเจกต์ ยาวตามช่วงงานจริง แถบในแท่งคือความคืบหน้า
- **สรุปผล** แยกตามสถานะ ความคืบหน้าแต่ละโปรเจกต์ โปรเจกต์ที่ต้องจับตา และคนที่ถือโปรเจกต์
- ตั้งสถานะระดับพอร์ตโฟลิโอได้ ใช้ชุดเดียวกับสถานะโปรเจกต์
- **สิทธิ์ยังยึดตามโปรเจกต์** โปรเจกต์ปิดที่อยู่ในพอร์ตโฟลิโอจะไม่โผล่ให้คนนอกเห็น
  และไม่ถูกนับในตัวเลขสรุป แต่บอกตรง ๆ ว่ายังมีของที่มองไม่เห็นอยู่กี่อัน

### มุมมอง
| มุมมอง | ใช้ทำอะไร |
|---|---|
| รายการ | จัดกลุ่ม (รวมถึงตามฟิลด์ตัวเลือก คน วันที่) ลากสลับลำดับ เพิ่มงานรัว ๆ ได้ (Enter / Shift+Enter) กางงานย่อยในแถว เปิดปิด/เรียงคอลัมน์ (วันที่สร้าง สร้างโดย ทำเสร็จ แก้ไขล่าสุด ถูกบล็อกโดย กำลังบล็อก) สรุปท้ายคอลัมน์ตัวเลข (ผลรวม เฉลี่ย ต่ำสุด สูงสุด จำนวน) Shift/Ctrl+คลิกเลือกหลายแถว |
| บอร์ด | Kanban ลากข้ามคอลัมน์ จัดคอลัมน์ตามเซกชันหรือฟิลด์ตัวเลือก/คน (สีคอลัมน์ตามตัวเลือก) แบ่งแถว (swimlane) เลือกสิ่งที่แสดงบนการ์ด การ์ด S/M/L รูปปกจากไฟล์แนบรูป ยุบคอลัมน์ ลากหลายใบพร้อมกัน ดับเบิลคลิกแก้ชื่อบนการ์ด |
| **ไทม์ไลน์** | แผนภูมิแกนต์ พร้อมเส้นโยงลำดับก่อนหลัง (เส้นแดงเมื่อวันชนกัน) เส้นวันนี้ แถบงานที่ยังไม่มีวันให้ลากลงผัง คลิกแถวว่างเพื่อสร้างงานวันนั้น ระบายสีตามฟิลด์ |
| ปฏิทิน | สัปดาห์/เดือน รายโปรเจกต์หรือรวมทุกโปรเจกต์ งานหลายวันเป็นแถบยาว ลากเลื่อนวัน (งานที่รออยู่ขยับตาม) แถบ "ยังไม่มีวัน" คลิกวันเพื่อเพิ่มงาน ซ่อนเสาร์-อาทิตย์ ระบายสีตามฟิลด์ |
| **สรุปผล** | ตัวเลขรวม ความคืบหน้า แยกตามคน/ความสำคัญ/คอลัมน์ |

### ตัวกรองและแท็บมุมมอง
- **ตัวสร้างตัวกรอง** “+ เพิ่มตัวกรอง” ได้ทุกฟิลด์ทั้งในตัวและที่สร้างเอง เป็น / ไม่เป็น / มีอย่างใดอย่างหนึ่ง / ว่าง ช่วงวันที่ เทียบตัวเลข และ **“ฉัน”** ที่ตีความตามคนที่เปิดดู
- **เรียงหลายชั้น** (สูงสุด 5) คลิกหัวคอลัมน์ Shift+คลิกเพิ่มชั้น
- **มุมมองที่บันทึกไว้เป็นแท็บ** ต่อท้ายแท็บของโปรเจกต์ (สูงสุด 50) เปลี่ยนชื่อ ย้าย ลบ ตั้งเป็นมุมมองเริ่มต้น แก้แล้วกดบันทึกทับหรือทิ้งได้ ส่วนมุมมองบนแท็บในตัวจำไว้ต่อคนเอง
- **ทำสำเนาคอลัมน์** (เซกชัน) ลงโปรเจกต์เดิมหรือโปรเจกต์อื่น เลือกได้ว่าจะเอาอะไรไปด้วย ยุบ/ขยายทีละคอลัมน์หรือทั้งหมด Tab+N เพิ่มคอลัมน์

### ค้นหา ฟิลด์ และงานดูแลโปรเจกต์
- **ค้นหาด้วยตัวดำเนินการ** `"วลีตรงตัว"` `สบู่ | แชมพู` (หรือ OR) `-ไม่เอาคำนี้` `launch*` และ `( )` จัดกลุ่ม ค้นเจอรหัสงานและค่าฟิลด์ด้วย
- **ค้นหาขั้นสูง** (ปุ่มกรองในช่องค้นหา) เงื่อนไขชุดเดียวกับตัวกรองของโปรเจกต์ บวกโปรเจกต์/คอลัมน์ (รวม "ไม่อยู่โปรเจกต์ไหน") มอบหมายโดย ผู้ติดตาม มีไฟล์แนบ ถูกบล็อก/กำลังบล็อก เป็นงานย่อย ดูเป็นรายการหรือปฏิทิน **บันทึกการค้นหา** ไว้ที่แถบซ้ายได้ (ของแต่ละคน)
- **แก้หลายงานพร้อมกัน** ปุ่ม "เพิ่มเติม" บนแถบด้านล่าง ย้ายคอลัมน์ เพิ่มเข้าโปรเจกต์ ตั้งค่าฟิลด์ เพิ่มผู้ติดตาม เพิ่มแท็ก ทำเป็นหมุดหมาย/ขออนุมัติ ให้รองานอื่น รวมงานซ้ำ คัดลอกลิงก์ ผลรวมฟิลด์ตัวเลขของงานที่เลือก ทุกคำสั่งย้อนกลับได้ครั้งเดียว
- **ฟิลด์รหัสงาน** (REQ-12) เลขรันต่อโปรเจกต์ ค้นหาได้ พิมพ์ `@REQ-12` ในความเห็นได้ · **คลังฟิลด์ขององค์กร** ใช้ฟิลด์เดียวกันได้ทุกโปรเจกต์ แก้ที่เดียวเปลี่ยนทุกที่ · คำอธิบายฟิลด์ · แจ้งผู้ติดตามเมื่อค่าฟิลด์ตัวเลือกเปลี่ยน · แก้ชื่อ/สีตัวเลือกได้ภายหลัง
- **หน้าแท็ก** (กดแท็กที่ไหนก็ได้) เปลี่ยนชื่อ/ลบแท็กทั้งองค์กร
- **นำเข้า CSV แบบจับคู่คอลัมน์** ดูตัวอย่างก่อน เลือกการเข้ารหัส สร้างฟิลด์ใหม่จากคอลัมน์ ผู้ร่วมงาน งานหลัก ลำดับก่อนหลัง · **ส่งออกโปรเจกต์เป็น JSON** · **ปฏิทิน .ics** ของงานของฉันหรือของโปรเจกต์ · **พิมพ์รายการงาน**
- **บทบาทในโปรเจกต์** (ข้อความอิสระ แสดงที่ภาพรวม) · **ขอสิทธิ์เข้าโปรเจกต์ปิด** จากลิงก์ (เกิดงานให้เจ้าของกดให้สิทธิ์ได้ในแผงงาน) · **แปลงงานเป็นโปรเจกต์** · ถังขยะเฉพาะโปรเจกต์

### Gantt
แถบเครื่องมือแยกสองฝั่งแบบเดียวกับ Asana ซ้ายเลื่อนดูช่วงเวลา ขวาปรับมุมมอง

- ซูม 6 ระดับ วัน สัปดาห์ เดือน ไตรมาส ครึ่งปี ปี
- **ระบายสีแท่งงาน** ตามสีโปรเจกต์ ความสำคัญ ผู้รับผิดชอบ ชนิดงาน สถานะอนุมัติ หรือความคืบหน้า พร้อมคำอธิบายสี
- **เส้นฐาน (baseline)** — เก็บวันที่ของทุกงานไว้เป็นแผนเดิม แล้วเทียบว่าตอนนี้หลุดไปกี่วัน
- **เลื่อนงานที่รออยู่ให้อัตโนมัติ** — ขยับงานหนึ่ง งานที่รอต่อจะถูกดันตามให้ลำดับยังถูกต้อง คงระยะห่างที่ตั้งใจเว้นไว้ และไม่แตะงานที่ทำเสร็จแล้ว
- คอลัมน์ฝั่งซ้ายเปิดปิดได้ กำหนดส่ง ระยะเวลา รออะไรอยู่ บล็อกงานอะไร
- กางงานย่อยเข้ามาในผังได้ ค้นหาเพื่อเน้นแถว และบันทึกทั้งชุดเป็นมุมมองพร้อมไอคอน

### บัญชีและการตั้งค่าของฉัน
กดที่ชื่อตัวเองมุมซ้ายล่าง เปิดเมนูบัญชี ตั้งสถานะไม่อยู่ แก้โปรไฟล์ และเข้าหน้าตั้งค่า

- **โปรไฟล์** ชื่อที่แสดง ตำแหน่งงาน ฝ่าย เกี่ยวกับฉัน และสีประจำตัว
- **การแจ้งเตือน** เลือกได้เป็นรายชนิดว่าเรื่องไหนควรขึ้นในกล่องข้อความ
- **การแสดงผล** ธีม ภาษา วันแรกของสัปดาห์ โหมดแน่น เลขบรรทัด — เป็นค่าของแต่ละคน ไม่ใช่ของทั้งทีม
- **ทั่วไป** หน้าที่เปิดเมื่อเข้าแอป เปิดปิดคีย์ลัด ถามยืนยันก่อนลบ
- **สถานะไม่อยู่** มีวันสิ้นสุดเสมอและหมดอายุเอง ชื่อจะมีจุดส้มกำกับให้คนที่กำลังจะมอบงานเห็นก่อน

### งาน
- ชนิดงาน: งานทั่วไป / **หมุดหมาย** / **ขออนุมัติ** (อนุมัติ – ขอแก้ไข – ปฏิเสธ)
  ผู้อนุมัติคือผู้รับผิดชอบ (หรือคนที่แก้โปรเจกต์ได้) ผลการอนุมัติแจ้งคนสร้างงานและผู้ติดตาม และมีไอคอนสถานะในรายการกับบอร์ด
- **ลำดับก่อนหลัง** — งานที่ถูกบล็อกจะขึ้นป้ายเตือน และแจ้งผู้รับผิดชอบอัตโนมัติเมื่อพร้อมทำต่อ (กันการรอวนกันให้ด้วย)
- **งานทำซ้ำ** รายวัน / รายสัปดาห์ (เลือกได้หลายวัน) / รายเดือน / รายปี / ทุก N วันหลังทำเสร็จ —
  พอกดเสร็จ รอบถัดไปถูกสร้างพร้อมงานย่อย ค่าฟิลด์ ผู้ติดตาม แท็ก และโปรเจกต์ (ไม่รวมความเห็น) และกด “หยุดทำซ้ำ” ได้
- วันเริ่ม + เวลาเริ่ม + กำหนดส่ง + เวลาส่ง
- งานย่อยไม่จำกัดชั้น — ลากแถวไปวางกลางแถวอื่นเพื่อแปลงเป็นงานย่อย หรือใช้ “แปลงเป็นงานย่อยของ…” / “ย้ายออกเป็นงานหลัก”
  เรียง กรอง ซ่อนงานย่อยที่เสร็จแล้วในแผงงาน เตือนเมื่องานย่อยหลุดช่วงวันของงานแม่ และปุ่ม “จัดวันงานหลักให้ครอบงานย่อย”
- **งานติดตามผล** (Shift+Tab+F) **คัดลอกงานแบบเลือกได้ว่าเอาอะไรไปด้วย** **รวมงานซ้ำ** และ**มอบสำเนาให้หลายคน**
- **วางหลายบรรทัด** ลงช่องเพิ่มงานหรืองานย่อย = หนึ่งบรรทัดหนึ่งงาน (ถามยืนยันก่อน)
- **ถังขยะ 30 วัน** — งาน โปรเจกต์ และฟิลด์ที่ลบไปพักไว้ก่อน กู้คืนหรือลบถาวรได้ (คนทั่วไปเห็นของที่ตัวเองลบ ผู้ดูแลเห็นทั้งหมด)
- ความสำคัญ 5 ระดับ, แท็ก
- **ไฟล์แนบ** — เลือกไฟล์จากเครื่อง (≤ 2 MB ต่อไฟล์ ดาวน์โหลดกลับได้ด้วยชื่อเดิม)
- **รายละเอียดแบบมีรูปแบบ** — ตัวหนา ตัวเอียง ขีดเส้นใต้ ขีดฆ่า โค้ด หัวข้อ หัวข้อย่อย ลำดับเลข ลิงก์
  มีแถบเครื่องมือ คีย์ลัด พิมพ์ `- ` / `1. ` แล้วกลายเป็นรายการเอง และวางมาร์กดาวน์หรือข้อความจาก Docs/Word แล้วติดรูปแบบมา
- **@ อ้างถึง** คน งาน หรือโปรเจกต์ ได้ทั้งในรายละเอียดและความเห็น — อ้างถึงงานไหน งานนั้นจะมีบันทึกว่าถูกอ้างถึงจากที่ใด
- **ความเห็นแบบเธรด** — ตอบกลับได้หนึ่งชั้น ยุบไว้เป็นแถว “n การตอบกลับ” แจ้งเฉพาะคนในเธรดกับคนที่ถูก @
  แก้/ลบความเห็นของตัวเอง ปักหมุดความเห็นไว้บนสุด คัดลอกลิงก์ตรงถึงความเห็น อีโมจิตอบรับ
  และ**ร่างความเห็นค้างไว้ได้** ปิดแผงหรือรีเฟรชแล้วไม่หาย (เก็บในเครื่อง ไม่ขึ้นไปที่ข้อมูลกลาง)
- **ผู้ติดตาม**, ถูกใจ (♥), คัดลอกงาน, **บันทึกเป็นเทมเพลต**
- **งานชิ้นเดียวอยู่ได้หลายโปรเจกต์** — จุดเด่นของ Asana ที่ Plane และ OpenProject ไม่มี

### จัดการและติดตาม
- **กล่องข้อความ** — แท็บกิจกรรม / บุ๊กมาร์ก / เก็บถาวร ทำเป็นอ่านแล้วหรือยังไม่อ่าน กรองตามคน โปรเจกต์ @พูดถึงฉัน มอบหมายให้ฉัน ที่ฉันมอบหมาย ยังไม่อ่าน
  เรียงใหม่สุดหรือเกี่ยวข้องที่สุด แบบละเอียดหรือกะทัดรัด สร้างงานติดตามผลจากรายการได้ และ**ห้ามรบกวน** (พักชั่วคราวหรือตั้งช่วงเวลาประจำวัน)
  การแจ้งเตือนรายโปรเจกต์ (อัปเดตสถานะ ประกาศ งานใหม่) ตั้งเองได้ต่อคนจากเมนูโปรเจกต์
  เตือน**ครบกำหนดพรุ่งนี้ / วันนี้ / เลยกำหนด** และสรุปงานเลยกำหนดทุกวันจันทร์ (สร้างตอนเปิดแอปและทุกชั่วโมงที่เปิดค้างไว้ ปิดเป็นรายชนิดได้)
- **ตัวกรอง / เรียง / จัดกลุ่ม** และ **บันทึกมุมมอง** ไว้กดซ้ำ
- **เลือกหลายงาน** แล้วแก้พร้อมกัน (เสร็จ, มอบหมาย, ความสำคัญ, กำหนดส่ง, ลบ)
- **กฎอัตโนมัติ** — ลากเข้าคอลัมน์ไหนแล้วให้ทำอะไรต่อ
- ฟิลด์กำหนดเอง: ข้อความ / ตัวเลข / ตัวเลือกเดียว / หลายตัวเลือก (มีสี) / วันที่ / บุคคล
  ฟิลด์ตัวเลขแสดงเป็นสกุลเงิน (THB USD EUR JPY CNY SGD …) เปอร์เซ็นต์ หรือหน่วยกำหนดเอง ตั้งทศนิยม 0–4 ได้ ใช้ทั้งในตาราง แผงงาน และ CSV
- **มุมมองของโปรเจกต์** ภาพรวม รายการ บอร์ด ไทม์ไลน์ Gantt ปฏิทิน สรุปผล **ประกาศ** และ**ไฟล์** — เปิดปิดได้ทีละมุมมอง
- **ประกาศของโปรเจกต์** เรื่องที่ไม่ได้ผูกกับงานชิ้นไหน เช่น สรุปประชุม แจ้งสมาชิกให้อัตโนมัติ
- **ปักหมุดโปรเจกต์** ไว้บนสุดของแถบซ้าย (ของแต่ละคน) และหน้ารวมโปรเจกต์
- **สถานะโปรเจกต์** 6 แบบ ตามแผน เสี่ยง หลุดแผน พักไว้ก่อน เสร็จสมบูรณ์ ยกเลิกแล้ว — ตั้งได้จากป้ายข้างชื่อโปรเจกต์ พร้อมเก็บรายงานย้อนหลัง
- คัดลอกโปรเจกต์เป็นเทมเพลต, เก็บเข้าคลัง
- **โอนงานต่อ** — ปิดบัญชีใครแล้วระบบบังคับให้ตัดสินใจเรื่องงานที่ค้างก่อน จะได้ไม่มีงานผูกกับบัญชีที่เข้าไม่ได้
- **ค้นหา** จากชื่องาน รายละเอียด ชื่อผู้รับผิดชอบ แท็ก และชื่อโปรเจกต์ เรียงตามความตรง
- **ย้อนกลับ** ได้ 25 ขั้น
- **ลิงก์ตรงถึงงานและถึงความเห็น** — `#/task/<รหัสงาน>` และ `#/task/<รหัสงาน>/c_<รหัสความเห็น>`
  วางลงช่องที่อยู่ตอนเปิดแอปค้างไว้ก็ได้ ระบบพาไปที่งาน เลื่อนไปหาความเห็นและไฮไลต์ให้
- **หน้าผู้ดูแลระบบ** — เพิ่ม/เอาสมาชิกออก ตั้งสิทธิ์ 4 ระดับ ดูที่เก็บข้อมูล และบันทึกกิจกรรมย้อนหลัง
- โหมดสว่าง / มืด / ตามระบบ
- สำรองและกู้คืนข้อมูล (ดาวน์โหลดไฟล์ หรือคัดลอก/วาง JSON)

## ⚠️ เรื่องข้อมูล ต้องอ่าน

Orbit ทำงานได้สองโหมด แยกกันชัดเจน

### โหมดทีม (ล็อกอินด้วยบัญชีบริษัท)

ทุกคนเห็นข้อมูลชุดเดียวกัน เก็บเป็นไฟล์ JSON ไฟล์เดียวบน **SharePoint ของบริษัท**
ข้อมูลไม่ออกนอก Microsoft 365 ของเรา ไม่มีเซิร์ฟเวอร์ตัวกลาง ไม่มีค่าบริการรายเดือน

- แก้แล้วเห็นทันที ระบบส่งขึ้นให้เองหลังหยุดพิมพ์ ~1.5 วินาที
- ดึงงานใหม่จากเพื่อนร่วมทีมทุก 15 วินาที
- เน็ตหลุดยังทำงานต่อได้ กลับมาแล้วส่งเอง
- ถ้าสองคนแก้พร้อมกันจริง ๆ ระบบจะ**หยุดถาม** ไม่ทับงานใครเงียบ ๆ

วิธีเปิดใช้ ดู **[SETUP-M365.md](SETUP-M365.md)** — ต้องให้ผู้ดูแลระบบตั้งค่าครั้งเดียว

### โหมดเครื่องเดียว (ยังไม่ได้ตั้งค่า หรือเลือกเอง)

ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์เครื่องที่เปิด** เท่านั้น

- แต่ละเครื่องเห็นข้อมูลของตัวเอง ไม่ sync กัน
- ถ้าล้าง browsing data ข้อมูลจะหายทั้งหมด
- กด **ตั้งค่า → ดาวน์โหลดสำรอง** เก็บไฟล์ JSON ไว้สม่ำเสมอ

ถ้าเบราว์เซอร์ไม่ยอมให้เก็บข้อมูล (โหมดส่วนตัว หรือหน้าที่ถูก sandbox) ระบบจะถอยไปเก็บในหน่วยความจำแทน ใช้งานได้ครบทุกอย่างแต่ข้อมูลหายเมื่อรีเฟรช และจะมีข้อความเตือนขึ้นให้เห็น

การสลับผู้ใช้ในเมนูล่างซ้ายมีไว้ทดสอบมุมมองของแต่ละคนในโหมดเครื่องเดียว พอเข้าโหมดทีมแล้วจะกลายเป็นเมนูบัญชีจริง

### สามจุดที่ตั้งใจออกแบบไว้

**1. ย้ายขึ้น server ได้โดยไม่แตะ UI**
`store.js` ซ่อนการบันทึกไว้หลัง `hydrate()` กับ `persist()` แค่ 2 ฟังก์ชัน เวลาต่อ Supabase ให้แก้แค่สองตัวนั้น `render.js` และ `main.js` ไม่ต้องแตะเลย

**2. `memberships` คือหัวใจ**
เป็นตารางกลางระหว่าง task กับ project ทำให้งานชิ้นเดียวอยู่ได้หลายโปรเจกต์ และ `position` เป็นเลขทศนิยม (fractional index) — ลากแทรกระหว่างตำแหน่ง 2 กับ 3 ได้ 2.5 อัปเดตแถวเดียวจบ ไม่ต้องเรียงใหม่ทั้งคอลัมน์ เรื่องนี้จะสำคัญมากตอนหลายคนลากพร้อมกันบน server จริง

**3. `stories` รวมความเห็นกับบันทึกกิจกรรม**
ตารางเดียว ได้ timeline ต่อเนื่องและ audit trail ฟรี
ความเห็นมี `parentId` (เธรดชั้นเดียว) `pinned` `editedAt` `deleted` และ `reactions` ตั้งแต่ SCHEMA 7

**4. ข้อความมีรูปแบบเก็บเป็นมาร์กดาวน์ย่อ ไม่ใช่ HTML**

## ยังไม่มี (ตั้งใจข้าม)

พอร์ตโฟลิโอกับหน้าผู้ดูแลระบบทำแล้ว (ดูด้านบน) ที่ยังไม่มีคือ
Goals/OKR, Workload, Capacity planning, Timesheet, Forms, ทีม (Teams), หน้าเอกสาร (Pages) และระบบอัตโนมัติแบบหลายเงื่อนไข
— กำลังทยอยทำตามแผนใน **[docs/ASANA-PARITY.md](docs/ASANA-PARITY.md)** ส่วนของที่ต้องมีเซิร์ฟเวอร์
(แจ้งเตือนทางอีเมล/Teams, ฟอร์มสาธารณะ, API/webhook) รอหลังมีระบบหลังบ้านจริง

## ขั้นต่อไป

โหมดทีมพร้อมใช้แล้ว (ข้อ 4 กับ 5 ของแผนเดิมเสร็จไปแล้ว) ที่เหลือคือของที่จะทำเมื่อทีมโตเกินไฟล์เดียว

1. ถ้าเกิน ~20 คน หรือเจอ “ข้อมูลชนกัน” บ่อย → ย้ายไปฐานข้อมูลจริง (Supabase)
2. เขียน `hydrate()` / `persist()` ใน `store.js` ใหม่ให้เรียก Supabase client
3. เปิด Row Level Security คุมสิทธิ์ที่ชั้นฐานข้อมูล
4. แจ้งเตือนเข้า Teams เมื่อถูกมอบหมายงาน (Graph มี API ให้แล้ว)

โครงสร้างตอนนี้รองรับข้อ 1–2 อยู่แล้ว เพราะการบันทึกถูกซ่อนไว้หลังสองฟังก์ชันนั้น
